# Marc Week Seven Netting Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Livrer un Clearing Engine v1.2 qui calcule les compensations bilatérales et multilatérales, traite des batches, détecte les fenêtres suspectes et qualifie un million de transactions.

**Architecture:** Le paquet `clearing.v12` consomme les transactions validées par v1.1. Les APIs exactes du TP restent disponibles comme adaptateurs; la chaîne applicative utilise des résultats nommés. Les benchmarks produisent des mesures, tandis que les tests vérifient uniquement les résultats et les invariants.

**Tech Stack:** Scala 3.3.8, ScalaTest 3.2.19, scala-parallel-collections 1.2.0, sbt, Java 17 et 21.
