# Marc Week Nine Pure Core Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Deliver Marc's Clearing Engine v2.0 as a deterministic pipeline of pure functions with all file and console effects isolated at the application edge.

**Architecture:** Add `clearing.v20` beside the accepted v1.3 package. The pure pipeline parses text, validates and cleans transactions, applies curried configuration, anonymizes IBANs, and calculates net positions. `IOBridge` reads files and `ClearingReporter` prints the already-rendered report.

**Tech Stack:** Scala 3.3.8, ScalaTest 3.2.19, existing clearing domain and SHA-256 utility, SBT 1.10.11, Java 17 and 21.

**Step 3: Implement composed stages**

Expose:

```scala
val splitLines: String => List[RawTransaction]
val parse: List[RawTransaction] => ParsedBatch
def validate(config: PureEngineConfig): ParsedBatch => ValidatedBatch
def prepare(config: PureEngineConfig): ValidatedBatch => PreparedBatch
val calculate: PreparedBatch => PureClearingReport

def configure(config: PureEngineConfig): String => PureClearingReport =
  splitLines andThen parse andThen validate(config) andThen
    prepare(config) andThen calculate
```

Reuse pure validation rules and SHA-256, but do not import Spring, HTTP, file,
clock, UUID, or console APIs. Preserve rejection order.

**Step 4: Implement deterministic rendering**

Sort map entries before rendering. Render hashes, never raw IBANs. Render fees
separately from net positions.

**Step 5: Prove determinism**

UTF-8 byte array to the first result. Capture standard output around the core
call and require it to stay empty.

Expected: v2.0 and v1.3 tests pass together.
