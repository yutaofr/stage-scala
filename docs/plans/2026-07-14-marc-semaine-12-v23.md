**Step 3: Implement the minimum API**

```scala
trait Functor[F[_]]:
  extension [A](fa: F[A])
    def map[B](f: A => B): F[B]

object Functor:
  def transform[F[_], A, B](fa: F[A], f: A => B)(using
    functor: Functor[F]
  ): F[B] = functor.map(fa)(f)

  given Functor[List] with
    extension [A](values: List[A])
      def map[B](f: A => B): List[B] = values.map(f)

  given Functor[Option] with
    extension [A](value: Option[A])
      def map[B](f: A => B): Option[B] = value.map(f)

case class Box[A](value: A)

object Box:
  given Functor[Box] with
    extension [A](box: Box[A])
      def map[B](f: A => B): Box[B] = Box(f(box.value))
```

**Step 3: Implement the pure pipeline**

`V23Pipeline.runPure` utilise un seul `for-yield` sur `MonadicLogger` :

```scala
for
  input <- observeInput(raw)
  result <- clear(config, hash)(input)
  audited <- auditNetting(result)
  report <- export(format)(audited)
yield V23Execution(audited, report)
```

`auditNetting` remplace les positions par `V23Netting.positions` et journalise
la somme. `export` importe un seul scope de serializer. Aucun état mutable,
`println`, fichier ou réseau ne doit entrer dans ce fichier.
