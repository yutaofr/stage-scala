# Marc Week Eight Java Interop Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Livrer un Clearing Engine v1.3 qui anonymise et horodate les flux, traverse de vraies frontières Java, récupère des taux par HTTP, injecte un repository Spring et conserve un netting MAD équilibré.

**Architecture:** Le paquet `clearing.v13` consomme les transactions validées par v1.1 et réutilise les calculs purs v1.2. Les collections Java, HTTP et annotations Spring restent aux frontières; le cœur convertit chaque transaction en MAD avant le netting et isole les devises sans taux.

**Tech Stack:** Scala 3.3.8, Java 17/21, JDK `MessageDigest`, `java.time`, `java.net.http`, `jdk.httpserver`, Spring Framework 6.2.19, ScalaTest 3.2.19, sbt.
