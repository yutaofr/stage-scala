# Marc Semaine 17 v3.2 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to
> implement this plan task-by-task and superpowers:test-driven-development for
> every behavior change.

**Goal:** Livrer un Clearing Engine v3.2 qui conserve le flux durable v3.1 et
le rend observable par logs JSON, Prometheus, OpenTelemetry, Jaeger, Grafana et
Alertmanager.

**Architecture:** Des ports d'observation no-op sont ajoutés aux étapes v2.2,
v3.0 et v3.1. Le paquet `clearing.v32` les implémente avec Logback, Micrometer
et OpenTelemetry, puis assemble le runtime. La stack Docker provisionne tous
les composants et artefacts d'exploitation depuis Git.

**Tech Stack:** Scala 3.3.8, Kafka client 4.3.0, Cassandra Driver 4.19.3,
Logback 1.5.38, Logstash Encoder 9.0, Micrometer 1.16.5, OpenTelemetry Java
1.63.0, Prometheus 3.12.0, Alertmanager 0.32.1, Grafana 13.0.2, Jaeger 2.18.0,
OpenTelemetry Collector 0.153.0, ScalaTest, Docker Compose.
