# Marc Semaine 16 v3.1 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Livrer un Clearing Engine v3.1 qui conserve les garanties Kafka de
v3.0, persiste un état de reprise Cassandra et expose les requêtes prévues par
la semaine 16.

**Architecture:** Le paquet `clearing.v31` réutilise les contrats v3.0 et ajoute
un repository asynchrone, un état `Received → Projected → Completed` et des
projections Cassandra idempotentes. Le coordinateur attend la persistance et
l'ack output/DLQ avant d'autoriser le commit, puis fait `seek` sur le premier
record non terminé en cas d'échec.

**Tech Stack:** Scala 3.3.8, Apache Kafka client 4.3.0, Apache Cassandra Java
Driver 4.19.3, Cassandra 4.1.11, Circe, ScalaTest, Docker Compose.
